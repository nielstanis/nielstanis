# Niels Tanis

Software security engineer & researcher, .NET developer, and security consultant focused on making software safer.

I have a background in .NET development, pentesting, and security consultancy, and have been a **Microsoft MVP**. Since 2015, I have worked at **Veracode** as a security researcher focused on languages and technologies related to Binary Static Analysis. Now I'm a software security engineer at **Tidalis**. 

I write and speak about application and software security, .NET, and the security challenges around modern development. I am also interested in **Rust**, **WebAssembly**, and **Blazor**.
